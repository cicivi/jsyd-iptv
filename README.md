# jsyd-iptv
江苏移动IPTV直播源  
ott魔百盒信源，自用不定期更新  
涵盖央视卫视、省内各市、NewTV频道等  
仅限于江苏移动网络环境下使用  
节目单来自 [老张的EPG](https://epg.51zmt.top/)，部分台标来自 [@taksssss](https://github.com/taksssss/tv) [@vircloud](https://github.com/vircloud/TVLogo) 与 [@dxdragon](https://github.com/dxdragon/myTV)  
同时在编撰过程中参考了 [@fanmingming](https://github.com/fanmingming/live) 的项目，对大佬表示膜拜  
感谢以上各位大佬的辛苦付出与帮助，以及恩山论坛各位大佬的细心整理  
如本项目有任何不当之处，欢迎批评指正
